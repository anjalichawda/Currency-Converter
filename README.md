# 💱 Currency Converter App

A React-based currency converter that fetches real-time exchange rates using an API.

## 🚀 Features
- Real-time currency conversion
- Swap currencies
- Responsive design
- Built with React + Tailwind CSS

## 🛠 Tech Stack
- React (Vite)
- Tailwind CSS
- Exchange Rate API

## 📦 Installation
npm install
npm run dev
